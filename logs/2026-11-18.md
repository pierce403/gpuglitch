## Pico 2 W flash preparation

The operator confirmed the board is a Pico 2 W. Live discovery found it in BOOTSEL on USB port `3-3`. The CLI image checks verified the board target, source digests, UF2 structure and SHA-256 for the 42,496-byte `build/pico2_w/ga100ctl_usb.uf2`. Picotool independently identified USB diagnostics version 1.0.0 for RP2350. [Expected image hash](../docs/provisioning.md#verified-build-outputs)

The BOOTSEL volume is read-only in this session. The underlying VFAT filesystem reports read/write and the block device reports no write protection. The next check is the `writable` field from the host terminal. The physical transfer was pending at this point.

At 12:18 PST, the operator requested installation. Flash event 1 in `build/firmware-history.sqlite3` stopped at the writable-volume check before copying any bytes. The session's approval policy rejected host execution of the same command. The target-specific command was supplied for execution from the host terminal.
